This Privacy Policy provides clear, transparent disclosures regarding how the Farmer Card browser extension collects, handles, processes, stores, and protects user data in compliance with the Google Chrome Web Store Developer Program Policies.

1. User Data Collection

The Farmer Card extension is a specialized digital utility designed solely to assist registered farmers and CSC VLEs in generating printable 300 DPI Farmer ID card PDFs from official Indian State & Central Farmer Registry web portals.

We collect only the narrowest data strictly necessary to perform this function:

  • Farmer Registry Information (from Active Tab): When you explicitly click "Pay & Generate Card" while on an authorized farmer registry page, the extension reads the text content displayed on that specific webpage. This includes: Farmer Name, Farmer ID, Relative Name, Date of Birth / Gender, Village, District, State, and Landholding plot numbers.
  • User-Supplied Input: If you enter the optional 4 masked Aadhaar digits (e.g. XXXX XXXX 1234) in the popup form, this is used solely for printing on the preview card face. We never collect or ask for full biometric or UIDAI data.
  • Payment & Transaction Identifiers: Razorpay Order ID and Payment ID generated during transaction verification for license activation and refund processing.

Data We DO NOT Collect:

  • We do NOT collect browser history, browsing activities, or bookmarks.
  • We do NOT collect passwords, credentials, cookies, or authentication tokens.
  • We do NOT collect personal communications, emails, contacts, or location data.
  • We do NOT collect financial credentials, CVVs, PINs, or banking passwords (payments are handled entirely on Razorpay's secure PCI-DSS servers).

2. Data Handling & Purpose of Processing

All data processed by Farmer Card is used exclusively for a single, transparent purpose:

  • Card Compilation & PDF Generation: To format the farmer's registry details into the standardized 300 DPI ID card graphic layout with regional font shaping (HarfBuzz) and export a printable double-sided PDF.
  • Transaction Verification: To confirm with payment gateways (Razorpay) that a ₹20 generation service fee was paid before releasing the final card PDF download link.

3. Data Storage & Retention Policy

  • In-Memory Ephemeral Processing: Webpage content transmitted to our backend rendering server is processed strictly in-memory (RAM) for the duration of the PDF rendering algorithm.
  • No Long-Term Personal Data Storage: We do NOT save, index, or store personal farmer records in any persistent database, CRM, user profile, or marketing list.
  • Automatic File Deletion: The generated PDF file is stored temporarily in a secure, ephemeral session cache solely to allow you to download your file. Temporary session files are automatically purged within 24 hours.
  • Local Browser Storage: The extension uses chrome.storage.local solely on your computer to store your most recent active session ID so that if you accidentally close the popup during payment, your paid download can be recovered. This data remains on your device.

We implement industry-standard technical measures to safeguard your information:

  • TLS 1.3 / HTTPS Encryption: All communications between the extension, backend servers, and payment processors are encrypted in transit.
  • Manifest V3 Compliance: All JavaScript executed is bundled locally within the extension package with no remote script execution or eval.
