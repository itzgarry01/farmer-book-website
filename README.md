# ਕਿਸਾਨ ਦੀ ਫਸਲ ਗਾਈਡ (Kisan Di Fasal Guide) — Official Website

> ਪੰਜਾਬ ਦੇ ਕਿਸਾਨਾਂ ਲਈ 40 ਉੱਚ-ਗੁਣਵੱਤਾ ਰੰਗਦਾਰ ਵਿਜ਼ੂਅਲ ਪੰਨਿਆਂ ਵਾਲੀ ਸੰਪੂਰਨ ਡਿਜੀਟਲ ਹੈਂਡਬੁੱਕ ਵੇਚਣ ਲਈ ਅਧਿਕਾਰਤ ਈ-ਕਾਮਰਸ ਵੈੱਬਸਾਈਟ।

## 🌾 Features
- **High-Converting Landing Page**: Custom-designed with earthy, natural agricultural colors (Forest green, harvest amber/gold, stone, cream).
- **Interactive Book Showcase**: 3D tilted book cover and high-resolution real page preview carousel.
- **Scientific vs Guesswork Comparison**: Interactive savings calculator showing ₹8,000 - ₹15,000 saved per acre.
- **Chapter Breakdown**: 8 structured modules detailing all 40 pages (PAU Ludhiana recommendations).
- **Real Farmer Testimonials**: Verified farmer reviews from Punjab districts (Ludhiana, Moga, Bathinda, Sangrur).
- **Seamless Checkout Modal**: Step-by-step Punjabi form + simulated UPI/QR/Card payment + instant 53 MB PDF download with celebratory confetti.
- **Vercel Edge Ready**: Static PDF asset delivery via CDN without serverless payload limits.

## 🚀 Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: canvas-confetti, Tailwind animations

## 💻 Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Production Build
```bash
npm run build
npm start
```

## 🌐 Deploy to Vercel
1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and import the repository.
3. Deploy with default Next.js settings!
